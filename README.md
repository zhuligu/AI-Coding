## 一、系列定位

**一句话定位**：不教语法，教"用 AI 做产品"的完整方法论——从想法到上线，手把手带零基础普通人走通全流程。

**目标读者**（画像由"参考素材 + 2026 年行业数据"共同得出）：

| 人群 | 痛点 | 占比参考 |
|------|------|---------|
| 完全不会编程的普通人（学生、宝妈、职场人） | 有想法但做不出来，找程序员太贵太慢 | 63% 的 vibe coding 用户无编程背景（TechTimes, 2026-05） |
| 产品经理 / 运营 / 市场 | 想自己动手做工具/落地页，不再依赖开发排期 | 百度秒哒用户中 87% 完全不懂代码（量子位, 2026 AIGC 峰会） |
| 会一点编程的初级开发者 | 想提升 AI 协作效率，做出真正能上线的产品 | — |
| 想低成本创业/做副业的人 | 想验证 idea、做 MVP、跑通商业化 | OPC"一人公司"已成秒哒第一大用户群 |

**系列差异化**（区别于市面教程）：
1. 学"方法论"而非"语法"——参考 vibecoding.waytomaster.com 的 12 步方法论体系，AI 会写代码，你负责思考"要做什么"
2. 有真实项目贯穿——参考 AI News RSS（开源 MVP → SaaS 商业化）完整拆解
3. 有避坑体系——7 大常见陷阱 + 2026 年真实安全事故（Moltbook 泄露事件）警示
4. 紧扣 2026 年最新工具动态——Claude Code 2.1.x / Cursor 3.x / 国内工具（通义灵码、Trae、秒哒）

## 四、单篇文章模板（统一风格，参考极客时间《Claude Code 工程化实战》笔记）

1. **钩子开头**：一个反常识的事实 / 数据 / 真实场景（如"交互设计师一周做了个小程序"）
2. **破题**：这跟你有什么关系（非程序员视角的"为什么是现在"）
3. **正文**：结构化小标题 + 对比表 + 流程图 + 正反例代码块（金句加粗）
4. **避坑提醒**：每篇固定"常见坑 + 修正方案"小节
5. **行动清单**：3-5 条"今天就能做"的步骤（强化实操）
6. **结尾钩子**：预告下篇 + 引导关注 / 收藏 / 留言提问

**排版规范**：正文 15-16px，行距 1.75；小标题用编号体系（一、二、三…）；代码块加浅灰底色；关键数据用表格呈现。
