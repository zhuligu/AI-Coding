06｜环境搭建不求人：把 AI 编程环境跑起来

《非程序员 AI 编程实战》系列第 6 篇 · 需求分析第 6 步：环境搭建

上一期我们定了技术栈：以 web 应用为主，后端 Python（Flask），前端按三档走（HTML / Vue.js / React）。

现在轮到最让新人发怵的一关：环境搭建。

很多人学编程，倒在了第一步——装软件。教程第一句"先装好 Python 和开发环境"，然后冒出一堆术语：PATH、虚拟环境、Node.js、npm……还没开始，热情就凉了一半。

但 2026 年，这件事已经变了。对用 AI 编程的非程序员来说，"环境"不再是拦路虎，而是几个"下一步、下一步"的事。 这篇文章，我就把"装环境"这件事拆成"照着点就行"的保姆级流程——从 Python、虚拟环境、常用包，到一个能真正跑起来的网站。

结论先放这：非程序员最顺的环境 = 一个国内 AI 编程工具（推荐 CodeBuddy）+ 一个运行时（Python）+ 一个编辑器。不用科学上网、花钱少、中文界面，半小时内全部跑起来。

一、先搞懂：你的"环境"到底要装哪几样

别被"环境"两个字吓住。做 AI 编程，你只需要三类东西，像厨房三件套：

你要的是什么类比你都需要吗
AI 编程助手帮你写代码的智能体（CodeBuddy、Cursor、通义灵码…）你的"主厨"✅ 都要
运行时让代码真正跑起来的引擎（Python）灶台和火✅ 需要
编辑器 / 工作台你写需求、看代码、点运行的界面（IDE）操作台✅ 都要

好消息：很多国产工具把这三样打包好了。比如 CodeBuddy 智能 IDE，装好就能聊天、写代码、跑程序一条龙，不用你分别折腾。所以下面大部分步骤，本质是"装一个工具 → 打开 → 开干"。

💡 呼应第 2 篇：那 6 款顶级编程 Agent（Claude Code / Codex / Cursor / 通义灵码 / CodeGeeX / CodeBuddy）随便哪款都够用，选一个顺手、国内能直接用的。对非程序员，我们首选国内工具 + 国内模型——不用折腾网络、花钱少、中文语境好。本文以 CodeBuddy 为主演示，选了别的工具，安装逻辑一模一样。

二、Python 虚拟环境介绍

等你走到第四节"跑起你的第一个网站"时，会碰到一个隐藏概念：环境。这一节先把它讲透，顺便介绍两个专业开发者也常用的工具——venv 和 conda。

先泼盆冷水：对非程序员、做小项目，虚拟环境不是必选项。你在 CodeBuddy 里直接让 AI 装包、跑程序，绝大多数情况都能成。但了解它，能帮你避开"装了一堆东西后电脑越来越乱、项目互相打架"的大坑。

为什么需要"虚拟环境"？

打个比方：你接了两个不同的活儿，一个要 1 号扳手，一个要 2 号扳手。如果所有工具都扔在同一个大箱子里，扳手多了就会乱、会撞、会找不到。

Python 也一样：你做的每个项目（网站、脚本、分析）都依赖一些"功能包"（比如 Flask）。如果不加区分地全装到电脑的同一个 Python 里，会出现两个问题：

  • 版本打架：A 项目要 Flask 2.x，B 项目要 Flask 1.x，装一起就冲突。
  • 越来越乱：时间一长根本记不清哪个包是哪个项目用的，想清理都不敢动。

虚拟环境（virtual environment）就是给每个项目单独配一个"小工具箱"：箱子之间互不干扰，A 项目怎么折腾都不影响 B 项目。这也是为什么专业开发者几乎每个项目都开一个独立环境。

下面介绍两种最常见的"造箱子"工具。

工具一：venv（Python 自带，零安装）

venv 是 Python 官方内置的虚拟环境工具——只要你装了 Python（见第四节第 1 步），它就自带，不用额外下载。对非程序员、做普通网站 / 脚本，用它就够了。

① 创建环境（在你想放项目的文件夹里打开命令行）

python -m venv myenv

这会在当前目录生成一个叫 myenv 的文件夹，就是你的"小工具箱"。（名字随便起，不叫 myenv 也行。）

② 进入（激活）环境

  • Windows： 
    myenv\Scripts\activate
  • Mac / Linux： 
    source myenv/bin/activate

激活成功后，命令行最前面会出现 (myenv) 字样，意思是"你现在就在这个小箱子里干活"。

③ 在环境里装包、跑程序

激活后，你所有的 pip install 只会装进这个箱子，不影响别的项目。比如：

pip install flask
python app.py

④ 退出环境

干完活，敲一句就回到电脑的全局 Python：

deactivate

工具二：conda（数据科学 / AI 首选，需安装）

conda 比 venv 更"重"也更强：它不光能管 Python 的包，还能帮你装 Python 本身、装一些不是用 Python 写的科学计算库。做数据分析、AI、机器学习的人几乎都用它。

conda 有两个常见发行版：

  • Anaconda：全家桶，预装了上百个常用库，体积大（几个 G）。
  • Miniconda：只装最核心的部分，体积小、更轻量，新手推荐装这个。

① 安装 conda

去官网下载，按提示一路"下一步"即可：

  • Anaconda：https://www.anaconda.com
  • Miniconda：https://docs.conda.io/en/latest/miniconda.html

② 创建环境（指定 Python 版本，比如 3.12）

conda create -n myenv python=3.12

③ 激活环境

conda activate myenv

激活后同样会显示 (myenv) 前缀。

④ 在环境里装包

conda 自己有一个"应用商店"，也可以用 pip：

conda install flask
# 或者
pip install flask

⑤ 退出环境

conda deactivate

一句话怎么选？

你的场景推荐理由
普通网页应用 / 小脚本venvPython 自带，零安装，够用
数据分析 / AI / 机器学习conda能管 Python 本体和非 Python 库，省心
完全不想折腾让 CodeBuddy 代劳跟 AI 说"帮我建个虚拟环境并装好依赖"即可
💡 给非程序员的真心话：别被这一节吓到。等你走到第四节"装 Python、跑网站"那两步时，完全可以先不碰虚拟环境。等哪天项目变多了、开始报"包版本冲突"的错，再回来翻这一节也不迟。真要用的话，直接让 CodeBuddy 帮你建——你只需要知道"有这回事、为什么需要"就够了。

三、Python 包介绍与安装（新手最常问：那些"库"到底是什么）

你在第四节就会看到 pip install flask 这样的命令，也会看到 AI 一句话就帮你装好"Flask"。那这个 Flask 到底是个啥？这一节先讲清"包 / 库"是什么，再列几个非程序员最用得上的"神兵利器"，以及怎么装得又快又稳。

什么是"包"（也叫"库 / 模块"）？

我们用"做菜"做个比喻：Python 本身是一个灶台，能烧热、能下锅，但你要做出"红烧肉""糖醋鱼"这样的硬菜，得有现成的调料和配菜。包（package）就是别人已经配好的"料"——不同的调料和菜——把某类常用功能打包好，你直接拿来下锅，不用从零备料。

比如：

  • 你想做网站，有人写好了 Flask 这个包，装上就能用几行代码起一个网站；
  • 你想抓网页数据，有人写好了 requests 包，装上就能几行代码发网络请求；
  • 你想处理 Excel 表格，有人写好了 pandas 包，装上就能像表格软件一样算数据。

这就是为什么 AI 编程这么香：你不用自己写这些底层功能，只管"点菜"（告诉 AI 用哪个包、做什么），AI 帮你装、帮你调。对非程序员来说，"会用包"比"会写代码"重要得多。

非程序员最值得认识的几个包

包名干什么用典型场景
Flask轻量网站后端框架做能登录、能存数据的网页（本系列主线）
requests发起网络请求、调用 API查天气、查快递、接第三方数据（第 4 篇潮汐就是靠它查到的）
pandas表格数据处理与分析读 Excel / CSV、筛选统计、自动出报表
openpyxl读写 Excel 文件自动填表、批量改单元格、导出报表
matplotlib画图表（折线 / 柱状 / 饼图）把数据画成图，做可视化
Pillow处理图片（裁剪 / 压缩 / 加字）批量改图、加水印、生成缩略图
numpy数值计算底座大量数字运算（pandas 背后就靠它）
不用全装、不用全懂。用到哪个，让 CodeBuddy 帮你装、帮你写就行。这张表是给你"有个印象"：下次想做某件事，知道大概有现成工具，直接跟 AI 说"用 pandas 帮我处理这个 Excel"即可。

怎么安装一个包？

核心就一句命令（在命令行里敲，或在 CodeBuddy 里让 AI 帮你执行）：

pip install 包名

比如装上面提到的 pandas：

pip install pandas

装完，你的 Python 就多了这份"调料和菜"，代码里 import pandas 就能用。

💡 小技巧：一次装多个也行，空格隔开即可：pip install pandas openpyxl matplotlib。

国内镜像加速（装包慢？看这里）

pip 默认从国外官方源下载，国内网络常慢甚至超时。最简单的加速办法，是在安装命令后面加一句国内镜像源（相当于把"应用商店的服务器"搬到国内，速度飞起）：

pip install pandas --index-url https://pypi.tuna.tsinghua.edu.cn/simple

想一劳永逸地永久换源（设置环境变量）？具体命令见 第四节"第 1 步补充：pip 与国内镜像源（新手必看）"——那里有完整的图文步骤。

四、Python 网页应用（Flask）

这是本系列的主线，也是你做数据与 AI 网页应用要走的路。

第 1 步：装 Python（约 5 分钟）

网页应用的后端用 Python，所以先把它装好。

先说清楚 Python 是什么：简单讲，它就是让 AI 给你写的那些 .py 代码真正"跑起来"的引擎（就是上文"厨房三件套"里的灶台）。它本身是免费的，从官网下载安装即可。

① 下载 Python

打开浏览器，访问 Python 官方下载页：

  • 官网下载页（推荐，自动识别系统给最新版）：https://www.python.org/downloads/

进入后点页面上那个大大的黄色按钮，Windows 电脑点 "Download Python 3.x.x" 即可（64 位系统选 "Windows installer (64-bit)"）。

如果你想要直接拿到某个具体版本的安装包（比如文章截图用的 3.14.2），也可以不走下载页，直接下载安装管理器：

  • Python 3.14.2 安装包直链（Windows 64 位）：https://www.python.org/ftp/python/3.14.2/python-3.14.2-amd64.exe
小提示：那个 amd64 不是指 AMD 处理器，而是泛指"64 位 Windows"，Intel 和 AMD 的 64 位电脑都能装，放心点。

下载下来的是一个 .exe 文件，双击它就开始安装。

② 安装时最关键的一步：勾选 PATH

安装向导第一屏，请务必先勾选最下面的 "Add python.exe to PATH"（中文版叫"将 Python 添加到环境变量"），然后再点 "Install Now"。

  • 为什么要勾？ 勾了之后，你在命令行里直接敲 python 系统才找得到它。漏勾是新手 90% 报错的根源（详见第六节"坑 2"）。
  • 安装过程大概一两分钟，进度条走完点 "Close" 即可。

③ 验证装好了没

装完，按 Win + R，输入 cmd 回车，弹出黑色窗口后敲：

python --version

如果显示出 Python 3.14.2（或你装的版本号），恭喜——灶台点着了。

新手常踩：没勾 PATH，导致后面打不开 Python。如果忘了，不用卸载，重装一次、记得勾选即可，不是大事。

第 1 步补充：pip 与国内镜像源（新手必看）

Python 装好后，你手里其实还差一个"装插件的小助手"，它叫 pip——简单说，它就是 Python 的"应用商店"。你想用 AI 帮你装 Flask、装各种功能库，都得靠它。

情形 A：装完 Python 发现没有 pip，怎么办？

正常情况下，新版 Python 自带 pip。但万一你装完一敲 pip --version 提示"不是内部或外部命令"，说明 pip 没装上（比如老版本、或安装时某项被关掉了）。别慌，手动补一个就行：

  1. 打开 pip 官方安装说明页，照着做：https://pip.pypa.io/en/stable/installation/
  2. 先下载官方引导脚本 get-pip.py（页面里 "get-pip.py" 那段有下载链接）：https://pip.pypa.io/en/stable/installation/#get-pip-py
  3. 把 get-pip.py 保存到桌面，然后在它所在的文件夹里打开命令行（地址栏输入 cmd 回车），执行：
python get-pip.py

跑完，pip 就回来了。再敲 pip --version 应该能看到版本号。

情形 B：pip 装包太慢 / 卡住，怎么加速？

pip 默认从国外的官方源（PyPI）下载，国内网络经常慢、甚至超时。解决思路很简单：把下载地址换成国内的"镜像源"（相当于把应用商店的服务器搬到国内，速度快很多）。

方法一：临时换源（只这一次生效，最省心）

在装某个包的命令后面，加一句 --index-url 指定清华镜像：

pip install SomePackage --index-url https://pypi.tuna.tsinghua.edu.cn/simple

把 SomePackage 换成你要装的包名（比如 flask）即可。

方法二：永久换源（一劳永逸，推荐）

与其每次都加一长串参数，不如把镜像源设成默认。在 Windows PowerShell（用管理员模式打开） 里执行这一句：

[System.Environment]::SetEnvironmentVariable('PIP_INDEX_URL', 'https://pypi.tuna.tsinghua.edu.cn/simple', 'User')

执行后，以后你直接 pip install 包名 就会自动走清华镜像，又快又稳。

还想用别的源？国内还有中科大、阿里云、豆瓣等镜像，把上面网址换成对应地址即可。清华源 https://pypi.tuna.tsinghua.edu.cn/simple 是最常用的一个，新人记这一个就够。
💡 划重点：上面这些"下载 / 装 pip / 换镜像"的动作，其实大多数时候你不用自己敲命令——在 CodeBuddy 里跟 AI 说"帮我装好 Python 和 pip，并把下载源换成国内镜像"，它会一步步带你做完。这一节是给你"心里有底"，防止哪天卡住了不知道为什么。

第 2 步：装 CodeBuddy（约 5 分钟）

  1. 访问 copilot.tencent.com，下载 CodeBuddy 智能 IDE（Windows / Mac 都有）。
  2. 一路"下一步"安装，打开后用微信/QQ 登录。
  3. 第一次打开会提示"安装 Python 相关插件"，点允许即可——它会帮你把写 Python 要的辅助功能配齐。
如果你更习惯 VS Code，也可以装 VS Code + CodeBuddy 插件，效果一样。非程序员直接用 CodeBuddy 智能 IDE 最省事，少装一个软件。

第 3 步：跑起你的第一个网站（约 3 分钟）

  1. 在 CodeBuddy 里新建一个文件夹，建一个文件 app.py，把这段粘进去（这是第 5 篇见过的"最小网站"）： 
    from flask import Flask
app = Flask(__name__)

@app.route("/")
def hello():
    return "你好，这是我的第一个网站"
  2. 在 CodeBuddy 的对话窗里直接告诉 AI："帮我安装 Flask 并运行这个 app.py"。AI 会帮你执行： 
    pip install flask
python app.py
  3. 它跑起来后，会在窗口里给你一个本地网址（类似 http://127.0.0.1:5000）。按住 Ctrl 点这个链接，浏览器打开——看到那句"你好，这是我的第一个网站"，你的第一个网页应用就活了。
不必全懂这段代码。你只要知道：它能跑、你看得懂它在"说什么"（返回一句话），这就是非程序员验收 AI 成果的最低标准。

五、工具与模型选择方案（省钱又省心）

这一节专门讲"用哪个工具"和"用哪个模型"——非程序员最该先定下来的两件事。呼应第 2 篇，核心原则就一句：国内工具 + 国内模型首选，再用"多模型"思路省钱。

工具：首选国内工具，基本不用折腾

  • 国内工具（CodeBuddy / 通义灵码 / CodeGeeX）+ 国内模型（DeepSeek / 通义千问）：默认国内直连，不用科学上网，打开就能用。
  • 如果你选了 Claude Code / Cursor（国外工具）：需要科学上网才能访问，且 Claude Code 有封号风险、一旦封号无法使用；接国内模型还要额外配置，对非程序员偏麻烦。除非你明确需要它们的某项前沿能力，否则不建议新手从它们起步。

模型：用"多模型"思路省钱

非程序员、新手对成本敏感，所以选支持多模型的工具更划算——不同环节用不同档位的模型：

编程环节推荐模型理由
写需求文档、读说明、简单修改DeepSeek（便宜档）性价比之王，日常够用还便宜
日常写代码、调界面主力模型（如通义千问 Qwen）免费额度大、中文好
疑难重构、复杂报错最强档（旗舰模型）偶尔用，贵但能救急
批量生成、重复活便宜档量大就选便宜的
💡 省钱心法：让 AI 写代码，80% 的活儿用便宜模型就能搞定；只有卡住时再切旗舰模型。别从头到尾只用最贵的那个。

六、避坑：环境搭建最常见的 3 个错

坑 1：装软件前没看"认准官方"——搜"CodeBuddy 下载"、"Python 下载"会跳出一堆山寨站，可能带毒的或带广告的。记住：只从官网（copilot.tencent.com）或应用商店下。

坑 2：Python 没勾 PATH，后面全报错——症状是没有 python 命令。解决：重装、勾选 "Add to PATH"，或让 CodeBuddy 帮你检查环境变量。

坑 3：在"选哪个工具"上又纠结三天——第 5 篇就说了，默认选 Python + 国内工具，错不了。装一个顺手的，跑起来比选完美重要一万倍。

七、今天就能做的行动清单

  1. 先跑通主线：按本篇"四、Python 网页应用（Flask）"把 Flask 最小网站跑起来。新人用 Flask+HTML 起步最稳，先有"我做出来了"的实感。
  2. 装 CodeBuddy（copilot.tencent.com，微信登录），顺手把它当默认 AI 助手。
  3. 走通第四节第 3 步：跑起那个"你好，这是我的第一个网站"——你会有"我真的能做出东西"的实感。
  4. 记一笔：把"本地网址""模型档位"这类东西存到一个文档里，下次直接用。
  5. 别学语法：下一步是"怎么跟 AI 把需求说清楚"——第 7 篇《和 AI 对话的核心技能》。
